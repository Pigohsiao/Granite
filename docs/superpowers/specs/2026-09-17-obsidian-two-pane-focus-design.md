# Obsidian 風格雙欄專注模式設計

## 目標

將 Pigo Notes App 收斂為快速、唯讀的本機 Markdown 閱讀工具。介面採 Obsidian 啟發的深色雙欄結構：左側導覽，右側閱讀；不顯示未完成或會修改 Vault 的功能。

## 版面

- 左側：固定寬度的「檔案總管」，顯示 Vault 的實際資料夾階層。
- 右側：固定的唯讀 Markdown 預覽區，保留舒適留白與文件標題。
- 移除第三欄與雙／三欄切換。
- 移除右側的任務、Git、AI 分頁。
- 移除工具列的今天、任務、Git 與儲存操作；保留一個重新掃描檔案樹的精簡圖示。

## 檔案總管

- 資料夾以樹狀縮排顯示，檔案顯示在其父資料夾之下。
- 使用標準資料夾展開箭頭；所有資料夾在啟動與重新掃描後預設收合。
- 使用者按箭頭才展開或收合。選取檔案時，展開該檔案的祖先資料夾，使目前位置可辨識。
- 以輕微底色與細緻左側強調線標示目前選取的檔案。
- 隱藏系統與設定資料夾，沿用 VaultService 的既有排除規則。

## 效能與安全

- 選取檔案時只讀取目前 Markdown 檔案並渲染預覽。
- 不執行全 Vault 反向連結、任務或 Git 掃描。
- App 維持唯讀，不建立每日筆記、不修改原始 Markdown。

## 驗證

- UI 測試應驗證：只有兩個主要窗格、資訊面板不存在、舊工具列操作不存在。
- UI 測試應驗證：資料夾顯示為父子階層、初始為收合、展開後才看見子檔案。
- 選取檔案的測試應驗證：只顯示唯讀預覽且不觸發全 Vault 掃描。
